# StayInn – Accommodation Booking Platform

## Overview

StayInn is a simple accommodation booking platform designed to help users find apartments, houses, and villas in Armenia, Georgia, and Europe.

## Problems and Solution

The main problem I wanted to solve was making it easier to find suitable accommodation based on destination, dates, and number of guests.

The system allows users to:

* Search by city or property
* Select check-in and check-out dates
* Choose adults and children
* Browse available properties
* View prices, ratings, and guest reviews
* Register and log in to an account

The platform includes accommodation listings in destinations such as Yerevan, Tbilisi, Batumi, Paris, Rome, and Barcelona.

## Technologies Used

Python – Backend programming language
Flask – Web framework and application logic
HTML & CSS – User interface
JavaScript – Client-side functionality

## Property Details

Users can browse properties and see basic information such as the property name, location, rating, number of reviews, and price per night.
