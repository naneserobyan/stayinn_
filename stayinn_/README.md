# stayinn.com — Python/Flask

Русскоязычный демонстрационный сайт бронирования жилья. Реализован только на Python + Flask + HTML/CSS/JS.

## Запуск в VS Code
1. Откройте папку проекта.
2. Создайте окружение: `python -m venv .venv`
3. Активируйте его.
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите: `python app.py`
6. Откройте `http://127.0.0.1:5000`

## Есть
- Главная страница с 10 объектами из старого проекта.
- Поиск, фильтры и сортировка.
- Карта OpenStreetMap/Leaflet с ценовыми пинами.
- Страница объекта, галерея, удобства и отзывы.
- Модальное окно всех отзывов с «Показать ещё».
- Расчёт стоимости по ночам и демонстрационное бронирование.
- Модальные формы входа/регистрации без базы пользователей.
- Русский интерфейс.
